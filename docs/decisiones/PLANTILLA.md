# NNNN — Título de la decisión

- **Estado:** propuesta | aceptada | rechazada | reemplazada por NNNN
- **Fecha:** AAAA-MM-DD
- **Ámbito:** qué fuentes / componentes toca

## Contexto

Qué problema o situación llevó a decidir. Incluir mediciones o resultados de
pruebas si la decisión salió de una evaluación.

## Decisión

Qué se decidió, en una o dos frases. Alternativas descartadas y por qué (una
línea por alternativa).

## Consecuencias

Qué se gana, qué costo o deuda se asume, qué se rompería si alguien deshace
esto sin leer este ADR.

## Referencias

Bitácora, docs o commits con el detalle.
